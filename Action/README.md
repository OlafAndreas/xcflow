# xcflow install action

This action installs a pinned xcflow release on a Linux runner and verifies the download against its SHA-256 checksum; it runs on Linux only, so use `runs-on: ubuntu-latest`.
`xcflow setup` pins it by commit in the workflows it writes, and Dependabot bumps the pin when a new xcflow is out.
Each xcflow release publishes a matching `vX.Y.Z` tag here.
The files in this repo are generated by the release workflow of the xcflow repo from its `Action/` folder, and are not edited by hand.
