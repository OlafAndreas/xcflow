# Install xcflow

Xcode Cloud workflows as code. This action puts [xcflow](https://github.com/OlafAndreas/xcflow) on a GitHub Actions runner so your repo can:

- **Review** every Xcode Cloud workflow change in a pull request, as a plan comment: what will be created, updated or deleted.
- **Apply** the change when the pull request merges. Nothing reaches Xcode Cloud without review.
- **Catch drift**: when someone edits a workflow by hand in App Store Connect, a pull request shows up the next morning.

## Quick start

```bash
brew install olafandreas/tap/xcflow
xcflow setup
```

`setup` exports your workflows to `XcodeCloud/<bundle id>/*.json` and writes three GitHub workflows that use this action. Pinned by commit, bumped by Dependabot.

## Use it in your own workflow

```yaml
steps:
  - uses: actions/checkout@v7
  - uses: OlafAndreas/xcflow-action@v{{version}}
  - run: xcflow plan
    env:
      ASC_KEY_ID: ${{ secrets.ASC_KEY_ID }}
      ASC_ISSUER_ID: ${{ secrets.ASC_ISSUER_ID }}
      ASC_KEY_CONTENT: ${{ secrets.ASC_KEY_CONTENT }}
```

The secrets are an App Store Connect **team** API key: its id, issuer id, and the `.p8` file base64-encoded. `xcflow setup` can set them for you.

## What the action does

Downloads the xcflow {{version}} release for the runner (Linux x86_64 or arm64), verifies its SHA-256 checksum, and adds `xcflow` to the `PATH`. Nothing else: no repo access, no secrets, no network beyond the GitHub release. Runs on `ubuntu-latest`.

Action `vX.Y.Z` installs xcflow `X.Y.Z`. Each xcflow release publishes a matching tag here.
